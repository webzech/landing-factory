### 3. TECHNISCHES SEO CHECKLISTE
- [x] **Canonical URLs:** Jede URL besitzt ein sauberes `<link rel="canonical">` Tag.
- [x] **XML-Sitemap:** `/public/sitemap.xml` enthält alle 21 Core SEO URLs mit Prioritäten und Aktualisierungsdatum.
- [x] **Robots.txt:** `/public/robots.txt` erlaubt Crawling und verweist auf die Sitemap.
- [x] **HTML5 Semantik:** 1x H1 pro Seite, hierarchische H2- und H3-Gliederung, `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`.
- [x] **Schema.org Structured Data:** JSON-LD im HTML-Head für Organization, WebSite, LocalBusiness und PostalAddress.
- [x] **Mobile Responsiveness:** Getestet von 360px bis 4K ohne horizontales Scrollen.
- [x] **Performance & Core Web Vitals:** Schlanke Asset-Auslieferung, keine externen ungesicherten Tracker, schnelle Schriftarten-Einbindung.
- [x] **DSGVO / TDDDG:** Transparenter Cookie-Banner mit Widerrufsmöglichkeit und essenzieller Voreinstellung.

1. Rufen Sie https://search.google.com/search-console auf.
